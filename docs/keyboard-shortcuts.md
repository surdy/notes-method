# Notesmith Keyboard Shortcuts

Reference for Notesmith keyboard shortcuts in the macOS-first desktop app.

| Shortcut | Action | Description |
|----------|--------|-------------|
| **Navigation** | — | — |
| ⌘P | Palette (Files) | Open the unified palette in file search mode |
| ⌘⇧P | Palette (Commands) | Open the unified palette in command mode |
| ⌘K | Palette (Commands) | Alias for ⌘⇧P |
| ⌘⇧F | Palette (Files) | Alias for ⌘P |
| **Notes** | — | — |
| ⌘N | New Note | Create a new note with title and folder |
| ⌘D | Daily Note | Create or open today's daily note |
| ⌘⇧N | Quick Capture | Quick capture text to the default capture folder |
| ⌘⇧A | Archive Note | Route the current note to its archive destination |
| ⌘S | Save | Save the current note (auto-save handles this, but available for explicit save) |
| **Tabs** | — | — |
| ⌘W | Close Tab | Close the active tab |
| ⌘⇧T | Reopen Tab | Reopen the last closed tab |
| **View** | — | — |
| ⌘E | Toggle View Mode | Cycle: Source → Live Preview → Reading → Source |
| ⌘\\ | Toggle Right Rail | Show/hide the right sidebar context panel |
| **Table Editing (Source Mode)** | — | — |
| Tab | Next Cell | Move to the next table cell (auto-formats the table) |
| Shift+Tab | Previous Cell | Move to the previous table cell |
| Enter | Next Row | Move to the first cell of the next row (creates row if at end) |
| Escape | Exit Table | Move cursor below the table |
| ⌘⇧↑ | Move Row Up | Move the current row up |
| ⌘⇧↓ | Move Row Down | Move the current row down |
| ⌘⇧← | Move Column Left | Move the current column left |
| ⌘⇧→ | Move Column Right | Move the current column right |
| ⌘⇧Enter | Insert Row | Insert a new row below the current row |
| ⌘⇧Backspace | Delete Row | Delete the current row |
| ⌘⇧\\ | Insert Column | Insert a new column after the current column |
| ⌘⇧Delete | Delete Column | Delete the current column |

## Notes

- All shortcuts use `⌘` (Command) on macOS.
- Notesmith is macOS-first, so Linux and Windows key equivalents may differ.
- Shortcuts can also be discovered from the Command Palette (`⌘⇧P` or `⌘K`).
- Table editing shortcuts (Tab, Enter, Escape, ⌘⇧+arrows) only activate when the cursor is inside a markdown table in Source mode.
