Local by default, one click to go remote

Today the desktop only reaches a remote daemon when you export NOTESMITH_DESKTOP_DAEMON_URL in a launchd plist and relaunch. These mockups replace that with an in-app flow: the app opens local-only and you opt into a server when you want one.

Default: This Mac · 127.0.0.1:27183 Remote: a Notesmith daemon over Tailscale, e.g. 100.x.x.x:27183 When connected: vaults come from the server Reversible: switch back to local anytime

Which one?

OptionBest forEffortDiscoverability
A · Settings mode Shipping the capability fast; power users who live in Settings Low Medium — buried in Settings Start here
B · Status-bar switcher People who hop between a Mac and one+ servers regularly Medium High — always on screen Add later
C · Guided wizard First-run onboarding and less-technical setup moments Medium–High High — proactively surfaced Onboarding

Suggested path: ship A as the backing model + UI, then layer B's status-bar pill as the everyday entry point that reuses A's saved servers, and reuse the same fields inside C for first-run. All three share one persisted list of servers and the existing daemon-URL switch under the hood.
