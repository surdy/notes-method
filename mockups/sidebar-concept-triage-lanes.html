Triage lanes — sketch from chat

source: web clip captured 11:42 #design unsorted

The sidebar holds views. Each view contains vertically stacked sections separated by horizontal rules. Sections show files and folders that match a condition. When a folder matches, it appears without its parent path — the section header carries the context.

For triage-style views (Inbox, Tasks, Today) a contextual middle list pane appears between the sidebar and the reading pane. Sidebar lanes scope the list. Selecting a row opens it on the right.

For the regular Files view the list pane collapses, so the reading pane gets the full width — the three-column layout is contextual, not always-on.

Tasks reuse the same list-pane component as Inbox; only the row template differs (checkbox + due-date pill instead of source + snippet). That keeps one mental model: lanes scope a list, the list feeds the reader.
